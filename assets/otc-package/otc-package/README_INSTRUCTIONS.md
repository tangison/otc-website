# OTC Website Build Package — Instructions

This package is prep work only (research + assets). The actual site build happens
elsewhere (GLM 5.3 via zcode). Here's what's in here and what to do with it.

## Contents

```
otc-package/
├── README_INSTRUCTIONS.md   <- this file
├── content-brief.md         <- all copy, facts, structure, brand colors, gaps to confirm
└── images/
    ├── otc-logo.png                    <- official crest, use as-is for header/favicon
    ├── otc-student-classroom.png       <- real student photo, hardhat + coveralls
    └── otc-student-horticulture.png    <- real student photo, garden/horticulture work
```

## What to do with it

1. **Read `content-brief.md` first** — it has the confirmed contact details, vision/mission,
   full course list (with pricing where known), institutional units, partners, sampled
   brand colors (hex codes), a suggested page structure, and a section at the bottom
   flagging data that still needs client confirmation before publishing.

2. **Use the three images in `/images` as the only "real" OTC photography.** They're
   verified authentic (extracted from OTC's own profile PDF, not stock). Don't source
   or generate replacements for these — use them directly.

3. **Do not invent additional "real" photos or staff bios.** Where the brief flags a gap
   (course pricing, staff names, application form), either leave a placeholder clearly
   marked for the client to fill in, or source clearly-labeled generic stock — never
   present a stock photo as if it's an OTC student or facility.

3a. **Need more images than the 3 provided?** content-brief.md § "Where to get more images"
    has the full guidance, but in short:
    - First choice: ask the client to pull more real photos from OTC's own Facebook,
      Twitter/X (@collegeongenga), or LinkedIn pages — those are real and usable like
      the provided 3.
    - Fallback: free stock from Unsplash / Pexels / Pixabay (commercial-use-safe, no
      attribution required). The brief has a ready-made search-term table, one row per
      course/section, biased toward African/Namibian context rather than generic
      Western stock.
    - Don't pull images straight off ongenga.com or otc.nam.na without checking rights —
      some of what's on those sites is itself unlicensed stock.

4. **Brand colors** are in the brief — navy `#01007F` primary, gold `#D9AA1C` accent,
   white background, sparing use of red `#FB0103` and green `#147C2D`.

5. **Contact details to use on the site:** phone +264 85 8030415, email info@otc.nam.na —
   this was the client's explicit choice over the alternate set found on ongenga.com.
   The brief explains the discrepancy; it doesn't need to be re-litigated, just used as-is.

6. If anything in the brief is ambiguous or missing for the build, that's noted in
   content-brief.md §9 ("Known Data Gaps") rather than guessed at — check there before
   improvising content.
